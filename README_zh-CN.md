## 使用方法

### - 软件下载

1. 进入“下载软件”板块。
2. 选择您需要的平台（Windows、Android、iOS、MacOS、Linux）。
3. 点击相应按钮开始下载。

使用这些配置文件有两种方式：

### 1. 单独复制配置文件

- 直接从网站复制单个配置文件
- 适用于所有 V2Ray 客户端
- 当配置文件发生变化时需要手动更新
- 最适合用于测试特定配置

### 2. 导入订阅链接

- 将订阅链接直接导入您的客户端
- 每2小时自动更新配置文件
- 长期使用更为便捷
- 仅适用于支持订阅链接的客户端
- 如果您的客户端支持该功能，这是推荐的使用方法

### 如何使用订阅链接

1. 复制所需协议的订阅链接
2. 打开您的 V2Ray 客户端
3. 找到“添加订阅”、“导入订阅”或“从网址添加”之类的选项
4. 粘贴订阅链接
5. 设置自动更新间隔（如果您的客户端支持此功能）
6. 点击更新/导入以加载配置文件
