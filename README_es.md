## Características

- Las configuraciones se actualizan cada 2 horas
- Siempre están probadas, activas y seguras
- Son de uso gratuito sin necesidad de suscripción
- Acceso a través de la web con enlaces de suscripción
- Soporte para varios protocolos, incluyendo mix, reality, vless, vmess, shadowsocks y trojan

## Cómo usarlo

### - Descarga del software

1. Vaya a la sección “Descargar software”.
2. Elija la plataforma que desee (Windows, Android, iOS, MacOS, Linux).
3. Haga clic en el botón correspondiente para comenzar la descarga.

Existen dos formas de utilizar estas configuraciones:

### 1. Copia individual de las configuraciones

- Copie las configuraciones individuales directamente desde el sitio web
- Adecuado para todos los clientes V2Ray
- Requiere actualizaciones manuales cuando cambian las configuraciones
- Ideal para probar configuraciones específicas

### 2. Importación del enlace de suscripción

- Importe el enlace de suscripción directamente en su cliente
- Actualiza automáticamente las configuraciones cada 2 horas
- Más práctico para un uso a largo plazo
- Solo está disponible en clientes que admitan enlaces de suscripción
- Método recomendado si su cliente lo soporta

### Cómo usar los enlaces de suscripción

1. Copie el enlace de suscripción para el protocolo que desee
2. Abra su cliente V2Ray
3. Busque opciones como “Agregar suscripción”, “Importar suscripción” o “Agregar desde URL”
4. Pégue el enlace de suscripción
5. Establezca el intervalo de actualización automática (si está disponible en su cliente)
6. Haga clic en actualizar/importar para cargar las configuraciones
