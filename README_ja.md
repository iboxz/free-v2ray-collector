## 機能

- 設定ファイルは2時間ごとに更新されます
- 常にテストが行われ、正常に動作し、安全です
- 利用に料金は一切かからず、サブスクリプションも不要です
- サブスクリプション用のリンクを使ったウェブベースのアクセスが可能
- Mix、reality、vless、vmess、shadowsocks、trojanなど、さまざまなプロトコルに対応しています

## 使用方法

### - ソフトウェアのダウンロード

1. 「ソフトウェアのダウンロード」セクションに移動します。
2. 必要なプラットフォーム（Windows、Android、iOS、MacOS、Linux）を選択します。
3. 適切なボタンをクリックしてダウンロードを開始します。

これらの設定ファイルの利用方法は2通りあります：

### 1. 個別の設定ファイルのコピー

- ウェブサイトから直接個別の設定ファイルをコピーする
- すべてのV2Rayクライアントで利用可能
- 設定ファイルが変更された場合は手動で更新が必要
- 特定の設定をテストするのに最適

### 2. サブスクリプションリンクのインポート

- サブスクリプションリンクを直接クライアントにインポートする
- 2時間ごとに自動的に設定ファイルが更新される
- 長期間にわたって利用する際により便利
- サブスクリプションリンクに対応しているクライアントでのみ利用可能
- クライアントが対応している場合は推奨される方法

### サブスクリプションリンクの使用方法

1. 必要なプロトコルのサブスクリプションリンクをコピーします
2. V2Rayクライアントを起動します
3. 「サブスクリプションの追加」、「サブスクリプションのインポート」、または「URLから追加」などのオプションを探します
4. サブスクリプションリンクを貼り付けます
5. 自動更新の間隔を設定します（クライアントで可能な場合）
6. 設定ファイルを読み込むために更新/インポートをクリックします
